# Промпт для нового поста (новый чат в Codex)

Копируйте всё между линиями в новый чат Codex, впишите тему вместо
`{ТЕМА}` — и отправляйте. Ничего больше знать не нужно, весь контекст
проекта уже внутри промпта.

---

Ты работаешь в проекте redkollegiya (папка уже открыта). Прочитай AGENTS.md
в корне и следуй ему буквально — это конвейер, который пишет посты для
Telegram-канала голосом конкретного автора, чистит от нейрослопа, фактчекает
и публикует.

Правила:
- Каждый скилл (Виноградов / Бахтин / Чуковский / Аграновский / Слопотрон /
  Розенталь / Мильчин) — не встроенная команда, а SKILL.md, который нужно
  открыть и прочитать на своём шаге. Пути и порядок — в AGENTS.md.
- Пройди шаги 1–6 (черновик → вычитка), показывай результат после каждого
  шага, коротко объясняя, что поправил и почему.
- `publish_telegram.py` НЕ запускай ни при каких условиях, пока я прямо не
  напишу «опубликуй». Просто покажи финальный текст (после Мильчина) и жди.
- Если нужна обложка — `find_cover.py` тоже запускай только по моей явной
  просьбе, не сам по себе.
- Если голосового профиля для этой темы/канала ещё нет — спроси, использовать
  ли нейтральный голос Бахтина или сначала собрать профиль через Виноградова.
