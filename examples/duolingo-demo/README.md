# Пример: полный прогон конвейера

Тестовый прогон всего конвейера от начала до конца, чтобы показать, что он
реально работает (не только на бумаге).

- `voice/guerrilla/` — голосовой профиль, собранный по 24 публичным постам
  канала t.me/GuerrillaMarketing (реклама и нативные интеграции вручную
  исключены из корпуса). **Тестовый профиль**, собран без интервью с автором
  канала — не выдаётся за настоящий заказ и не публиковался от имени канала.
- `pipeline-run/` — один пост (маркетинговый кейс Duolingo/Tesla Cybertruck,
  февраль 2025) прогнан через весь конвейер, шаг за шагом:
  `00-draft.txt` (Бахтин) → `01-chukovsky.txt` → `02-agranovsky.txt` →
  `03-slopotron.txt` → `04-rozental.txt` → `05-final.txt` (после Мильчина).
  `cover.jpg` — обложка, найденная `find_cover.py` (Unsplash, атрибуция в
  `cover.jpg.attribution.txt`).

Итоговый пост реально опубликован тестовым Telegram-ботом в рамках проверки
конвейера — само сообщение в этом репозитории не хранится, только текст.
